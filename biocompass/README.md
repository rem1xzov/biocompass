# Биокомпас — сайт и демо ИИ-агента

Концепт цифрового продукта для людей с ампутацией: лендинг + интерактивный кабинет
с агентом-проводником по протезированию.

Визуальное направление: тёплая редакционная типографика и большие оранжевые акценты
(референс `poehali.dev`) + мягкие карточки, воздух и спокойный интерфейс кабинета
(референс `gamma.app`). Медицинская тема подана без «клинического» холода и без
токсичного позитива.

## Запуск

Сайт статический и не требует сборки. Достаточно открыть `index.html` в браузере.

Если нужен локальный сервер (например, чтобы посмотреть с телефона в той же сети),
есть минимальный сервер без зависимостей:

```powershell
node serve.cjs
```

Затем открыть `http://127.0.0.1:8080`. Порт и хост задаются в начале `serve.cjs`.

## Публикация на GitHub Pages

Сайт статический, поэтому публикуется как есть — без сборки.

1. Создать репозиторий на GitHub и запушить ветку `main`:

   ```powershell
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) выкладывает сайт
   при каждом пуше в `main`. Адрес будет вида `https://<user>.github.io/<repo>/`.

Все пути в проекте относительные, поэтому сайт работает и из подпапки `/<repo>/`,
и при открытии `index.html` файлом.

## Структура

```
biocompass/
├── index.html          # лендинг + разметка кабинета
├── styles.css          # дизайн-система и адаптивность
├── app.js              # сценарии, чат-демо, маршрут, фильтры, модалки
├── assets/fonts/       # Manrope + Unbounded, кириллица и латиница
├── preview/            # скриншоты для показа
├── serve.cjs           # локальный статический сервер без зависимостей
├── QA.md               # отчёт о проверке
├── .github/workflows/  # автодеплой на GitHub Pages
├── .gitignore
├── .gitattributes
└── LICENSE             # MIT
```

Внешних зависимостей и сетевых запросов нет: шрифты лежат локально, все изображения —
inline SVG или CSS. Это позволяет открывать макет офлайн.

## Что работает

### Лендинг
- Первый экран с живым демо-агентом и сценариями входа.
- Три точки входа: «только узнал», «готовлюсь», «уже протезируюсь».
- Интерактивный маршрут из пяти этапов с аккордеоном и прогресс-диском.
- Блок возможностей, каталог типов протезов, база знаний с поиском.
- FAQ на нативных `details/summary`, CTA и медицинский дисклеймер.
- Мобильное меню, адаптивность от 375 px.

### Кабинет
- Чат с агентом: демо-ответы по темам (документы, клиники, стоимость,
  реабилитация, тревога, верхняя/нижняя конечность). Без API.
- Быстрые ответы, набор текста, Enter / Shift+Enter, индикатор печати.
- Персональный маршрут: чек-листы, прогресс, сохранение в `localStorage`.
- Карта организаций: демо-карточки, фильтры, выбор пина, избранное.
- База знаний: поиск, категории, статьи в модальном окне.
- Каталог протезов: фильтры по типу конечности.
- Контекст и сохранённые материалы в правой колонке.
- Мобильный drawer-сайдбар.

## Дизайн-токены

- Фон: тёплый `#F6F1E6`, бумага `#FCFAF5`.
- Текст: глубокий зелёно-чёрный `#14231C`.
- Акцент: оранжевый `#F45B2A`.
- Формы: крупные радиусы 22–36 px, тонкие линии, мягкие тени.
- Шрифты: `Manrope` для интерфейса, `Unbounded` для логотипа и служебных меток.
- Принцип: много воздуха, ясная иерархия, один сильный акцент на экран.

## Демо-ограничения

Это **не медицинский продукт** и не готовый ИИ. Важно перед запуском:

1. Ответы агента — заготовленные сценарии. Подключение LLM требует модерации,
   медицинской редактуры и защиты от опасных советов.
2. Организации, рейтинги и расстояния вымышлены и подписаны как демо.
3. Данные не отправляются на сервер: прогресс и избранное хранятся только
   в `localStorage` браузера.
4. Нет авторизации, CRM, записи, загрузки документов и оплаты.
5. Нужны юридическая проверка формулировок про ИПРА, политика обработки
   медицинских данных и отдельный протокол эскалации к живому специалисту.

## Что подключить следующим шагом

- API агента с системным промптом, ограничениями и цитатами из базы знаний.
- Проверенную базу организаций и протезных центров.
- Сохранение маршрута в аккаунте, экспорт чек-листа, напоминания.
- Запись на консультацию и передачу контекста специалисту.
- Аналитику воронки: первый вопрос → документы → клиника → консультация.
- Аудит доступности с реальными пользователями и скринридером.
